# Data

No external dataset is required. All collocation points, interfaces, exact solutions, and forcing terms are generated by the experiment scripts. Low-dimensional errors use tensor-product Gauss-Legendre quadrature. The high-dimensional example uses Monte Carlo samples.

The public project contains no input spreadsheets, trained checkpoints, or historical parameter-study workbooks. The paper solvers generate everything they need directly.

Random samples are generated in memory. The runner records its seed setting (`null` for normal paper runs) and complete arguments in `results/<name>/config_used.json`. No access permissions, login, or data download are needed.
